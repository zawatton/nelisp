#+TITLE: nelisp-gui-xcb — XCB transport and Cairo/Pango frontend

The frontend owns XCB/XKB transport, Cairo/Pango drawing and popup presentation.
Shared frame, keymap, mouse and command-loop modules own editor geometry,
canonical event interpretation, bindings, selection, scrolling and commands.
Pure-buffer fixtures use the shared edit adapter; native SKK/Evil buffers use
=emacs-command-loop-step= so package command hooks run normally.

Build from this private library copy with the supplied fixed runtime:

#+begin_src sh
export NELISP_BIN=/path/to/existing/nelisp-gui2
export EMACS=emacs DISPLAY=:91
python3 scripts/gui-daily-build.py
xvfb-run -a -s '-screen 0 1600x1000x24 -dpi 96 -nolisten tcp -noreset -extension GLX' python3 scripts/gui-daily-gate.py S3.2 --init=-Q --fixture=render --require-production-quit
python3 scripts/gui-daily-gate.py S3.3 --init=-Q --fixture=metrics
python3 scripts/gui-daily-gate.py S4.1 --init=-Q --fixture=skk-evil --keymaps=us,jp,de
python3 scripts/gui-daily-gate.py S4.2 --init=-Q --fixture=mouse-menu
#+end_src

No native compilation is involved. =bin/nemacs-xcb= rejects stale source/bundle
inputs and cold-loads the GUI-specific heap image. Native resources are acquired
after cold-load and destroyed in dependent-first order. The supplied runtime
supports production quit; acceptance waits for the complete process to exit.

S3.2 checks real shared glyph matrices, face rendering, AA/CJK fallback, cursor
movement and insertion, active-layout GC, BadWindow and private-server death.
S3.3 starts separate 96/144/192-DPI X servers. Pango measures font cells and
shapes runs, aligned to the shared fixed-cell grid. Public pixel queries and
position lists use those realized boxes. Gates inspect screenshot ink, cell
advances, fringes/margins, cursor movement and physical resize remainder pixels.

S4.1 uses installed ddskk/Evil sources and pinned GNU dependency sources copied
and byte-compiled only inside the gate's private fixture directory. Its tiny
UTF-8 dictionary and empty private dictionary are isolated from personal files.
The gate requires actual SKK/Evil activation, types romaji with XTest, checks
candidate cycling/kana and compares UTF-8 output against GNU with the same
fixture/script. It also checks server US/JIS/AltGr maps, group changes,
C/M/S/s modifiers, repeat, focus and quit. See =NEEDS-SHARED.md= for the shared
Custom/default-binding, command bookkeeping/advice, and native marker blockers.
The fixture pins the standard SPC conversion option explicitly; a focused probe
records the fixed reader's octal-character defect. A =--launcher= diagnostic override is recorded
in session metadata; an overlay run does not certify the production launcher.

S4.2 checks standard positioned button/drag/wheel events, live region selection,
point and CJK hits against cursor pixels, scrolling, resize, and commands from
the shared menu-bar/context keymaps. Menus are painted inside the window.

Each stage rejects explicit broken inputs or incorrect expected state. Result
JSON, source/runtime hashes, raw event/command logs and screenshots are retained
under =build/gui-daily/STAGE/=; the gates never stop the existing DISPLAY.
This is bounded stage acceptance, not a daily-driver or fractional-scaling claim.
The pixel-size helper covers the tested fixed-cell corpus; full GNU wrapping,
image/stretch glyphs and arbitrary window-text-pixel-size options remain outside
this fixture's coverage.

S4.3 selection acceptance:
#+begin_src sh
python3 scripts/gui-daily-gate.py S4.3 --init=-Q --fixture=selections --peer=xclip --bytes=1048576
emacs -Q --batch -L packages/nelisp-emacs-core/src -l packages/nelisp-gui-xcb/test/selection-policy.el
#+end_src

=emacs-select.el= owns GNU-style selection flags, clipboard preference,
per-selection text/timestamp tracking, and interprogram cut/paste hooks. Its
prefixed APIs work with an injected backend without application bootstrap;
=emacs-select-install= installs unprefixed shims only in standalone NeLisp.
The XCB frontend owns atoms, timestamp acquisition, ownership events and bounded
property transfers. It supports UTF8_STRING, Latin-1 STRING, polymorphic TEXT,
TARGETS and INTEGER/32 TIMESTAMP, plus INCR in both directions. Each conversion
uses a fresh unmapped requestor window, preserving unrelated input for the shared
loop. Limits: 4 MiB per value, eight concurrent sends, 3 s idle and 15 s total
transfer deadlines; native INCR buffers are released on completion, timeout,
requestor death and teardown. Server timestamps come from PropertyNotify.

The gate uses xclip for exact UTF-8 and 1 MiB PRIMARY/CLIPBOARD round trips,
ordinary kill-ring-save/yank, ownership predicates, SelectionClear and owner
death. Independent malformed/stalled peers exercise conversion/INCR timeouts,
announced/direct/running byte caps and type rejection. It retains screenshots,
bytes, hashes and complete production quit evidence. The launcher stays the
production =bin/nemacs-xcb=; the selections fixture is configured through an
isolated environment path, using a native buffer with the existing GNU copy
and shared yank command implementations.

The native-buffer fixture retires the otherwise unused pure bootstrap scratch
through =nelisp-ec-kill-buffer=. The existing native yank branch requires an
unambiguous current buffer substrate; mixed native/pure yank routing remains
owned by lane C1 and is not changed by this selection implementation.
