#+TITLE: GNU call-path port
#+STATUS: PLANNED

* Contract

GNU Emacs 31.1 is the oracle. This replaces Doc 219's incremental C1-C3
programme. Keep the original S4.2 limits: interpreter funcall/builtin
10x GNU; FX VM and bytecode 5x GNU. Include GC and average layouts
0, 700, 1400 and 2100. No performance result is claimed by this plan.

The inventory below classifies the transfer method, not completion.
=ported= means use GNU's algorithm; =adapted= names the NeLisp storage or
protocol needed; =impossible= states a current architectural/scope limit.
Every implementation step remains OPEN until semantic and measurement
receipts exist. An impossible component must remain explicit rather than
being replaced by an entry cache and called a GNU port.

All REPLs/tests inherit =ulimit -v 8388608=. Heavy builds and tests acquire
=/tmp/notes-heavy.lock=, one job at a time; close every REPL. Never raise
the cap. Changes are limited to call/evaluator entry, specpdl and bytecode
entry. Binding, regex, version and loader code retain their authorities.

* Implementation order

1. =Ffuncall= / =funcall_general= (=eval.c:3149,3185=): one
   =nl_gnu_funcall_w= entry preserves the original function, checks
   quit/depth, records the activation, checks GC, resolves aliases and
   retries autoload from the original function, dispatches, then finishes
   the activation once. =nl_gnu_function_cell_w= initially adapts the
   authoritative mirror-cell read; M02's direct symbol field is blocked
   as described below. No new function-cache experiment. Alias cycles
   need GNU's =fset= rejection (=data.c:912=) and a safe resolver when an
   internal writer has bypassed that invariant.
2. =funcall_subr= / =apply_lambda= (=eval.c:3254,3302,3322=): pass
   =(argc, WORD argv)= through the common entry. Use an EvalCtx-owned
   reusable argument reserve with a saved top, not a per-call cons spine
   or 32-byte argument views. Store offsets across calls/reserve growth
   and reacquire addresses after reentry; publish and mark/rewrite each
   worker's active prefix from introduction, including partial argument
   evaluation. Restore top only after exit debugging and cleanup finish.
   The compiler has no C =alloca= operation;
   =alloc-bytes= is a heap operation. Preserve left-to-right evaluation,
   optional nil fill, selected FFI arity, and GNU error identities. Fold
   A1's generated arity checks into this entry. Remove C1 if no formals
   compatibility view remains. Build a Lisp list only for =&rest= or a
   reflection adapter that actually requires it.
3. =funcall_lambda= (=eval.c:3350-3455=): read formals/captured environment
   once, bind by argv index, and enter the body directly. Use
   =nl_gnu_lambda_w= with the existing lexical-capture/promotion contract;
   dynamically special parameters go through the existing binding
   authority. Do not turn lexical parameters into unconditional dynamic
   bindings or silently change closure escape behavior.
4. =specbind= / =unbind_to= (=eval.c:3656,3940=): an EvalCtx-owned
   =nl_gnu_specpdl= reserve contains tagged binding, unwind and backtrace
   entries plus saved indices/argv offsets, never borrowed addresses that
   become stale on growth or reentry. Publish and mark/rewrite each
   worker's active prefix, including old binding values and functions.
   Store plain/local/default binding kinds;
   retain cand3's binding operations. =nl_gnu_unbind_to= copies and pops
   an entry BEFORE cleanup, preserves quit/result/error state, and covers
   normal return, throw, signal, debugger and frame-API adapters. Capture
   and reflection materialize durable objects only when requested.
5. =exec_byte_code= (=bytecode.c:365,496,766-816,894-927=): a single
   =wf_bytecode_execute_frame= loop switches between packed-arity lexical
   bytecode callees using an EvalCtx-owned reusable bytecode arena and
   =bc_frame=-style saved offsets. Save function, PC, top, frame pointer
   and handler/specpdl markers; return restores the caller in the same
   loop. Dynamic-list-formal bytecode keeps the general fallback. A
   stashed exit unwinds the innermost frame, restores its caller, then
   consults caller handlers. Add active-arena mark/rewrite traversal with
   the arena (=bytecode.c:396=); native-stack scanning alone is insufficient.
6. Conservative roots (=lisp.h:4444; alloc.c:5226=): use the existing
   native scan only where register spills, parked-worker stack extents,
   lookup-key authorization and precise-only mode are proven safe.
   Current worker publication contains env/root top, not native register
   snapshots/stack ranges. Retain explicit roots wherever M26's missing
   protocol prevents safe removal. Do not disable GC or omit its cost.

After EACH step: fresh binary, focused callfloor/capture/env-capture and
arity checks, then funcall AND builtin Ir in all three modes/four layouts
under the lock. Commit that step with GNU anchors and measured results.
If an unported representation/compiler/worker layer prevents the required
structure or caps, record its measured residual and stop; do not replace
the port with another tuning candidate. Run COMMON final verification
once only after the implemented path and original caps are satisfied.

* Direct-cell prerequisite and scope boundary

=nl_alloc_symbol_write=, =nl_intern_write_sexp= and =nl_make_symbol_write=
in =lisp/nelisp-cc-nlstr-direct-ops.el:248,539,460= use the symbol payload
for name capacity or identity; intern shares name bytes, not canonical
symbol objects/function cells. =nelisp_env_lookup_function_w= in
=lisp/nelisp-cc-env-lookup-function.el:52= reads mirror record slot 1.
=nl_pa_local_entry= in =lisp/nelisp-cc-variable-alias-public.el:138= copies
and publishes a replacement entry, explicitly invalidating the existing
N4 cache. A borrowed pointer into the old entry is therefore not authority.

The exact GNU transfer needs one stable cell handle shared by every
symbol view, maintained by constructors/interning/clone, all function-cell
writers and shadow publication, plus GC mark/rewrite and image relocation.
That crosses the current binding/object/loader limits. Within this scope,
the common entry can preserve the mirror read as an explicit adaptation;
it cannot claim GNU's no-hash symbol field. Measure the remaining lookup
cost and report this boundary if it prevents the required port/caps.
