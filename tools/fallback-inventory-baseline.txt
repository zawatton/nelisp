# Silent-degradation baseline (tools/nelisp-fallback-inventory.el).
# One "KIND COUNT" line per tracked kind.  Raise a number only in the
# commit that introduces the handler, and say there why the fall does
# not need recording.  Lower it whenever the ratchet notice says you can.
#
# Captured 2026-08-19 from lisp/ scripts/ tools/ (263 files).  These are
# starting values, not a target: nothing here has been reviewed, and the
# gate's job today is to stop the numbers growing while they are worked
# down.
#
# Why this gate exists, measured the same day: `compile-elisp-artifact'
# produced a 1391-byte .neln with an empty native section and printed no
# error at all, because the native compile falls back to bytecode inside
# a `condition-case'.  A green compile said nothing about whether
# anything was compiled natively.  The underlying bug -- write-region
# comparing bytes against characters -- was one symbol; finding it was
# not, because nothing recorded the fall.
#
# silent-fallback is the actionable kind: an error becomes a quieter,
# wrong answer.  ignore-errors is usually a deliberate probe and is
# counted apart for that reason.  bare-handler means `condition-case'
# discarded the error object before anyone could record it.

# 91 was never 91 silent degradations; it was 91 handlers the classifier
# could not read, in both directions:
#
#   23 re-raised or reported and were counted anyway.  13 in
#   nelisp-jit-strategy.el call `nelisp--signal-wrong-type' /
#   `nelisp--signal-arith', which are two-line wrappers around `signal' --
#   they raise a MORE specific error than the one they caught.  The rest
#   call this tree's own stderr printers: `nelisp-artifact--print-error',
#   `nelisp--cli-print-error', `nelisp-runtime-image--print-error'.  All
#   five names were verified to reach `signal' or stderr before being added
#   to the lists; none was taken on its name.
#
#   Going the other way, `nelisp-artifact--profile-log' was IN the recording
#   list while writing only when `nelisp-artifact-profile-stages' is set,
#   which it is not in a normal run -- so 18 handlers were being called
#   innocent for mentioning a logger that says nothing.  And five names in
#   that list (nl-safe-report, nl-safe-report-record, nelisp--log,
#   nelisp-log, nelisp--warn) are not defined anywhere in this tree, so they
#   could never have matched: an intention, not a measurement.
#
# What the remaining 48 are, having looked at every one:
#
#   ~30 are fast-path/slow-path falls where the slow path gives the same

#   one is wrong, and no cost otherwise.

#   nil for "did not compile", `load-source-file' answers nil for an invalid
#   or stale artifact so the caller reads source.  The nil IS the answer.
