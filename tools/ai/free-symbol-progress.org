#+TITLE: Native compiler: reject unbound free variables at build time, as GNU's byte compiler flags them

# Root cause of the word-heap S4.2 SIGSEGV (wh-s4f 7181d1cfd): a misplaced
# paren left `word` unbound in bf_env_capture_roots_w. The native
# compiler silently lowered the unbound symbol to a dynamic lookup through
# an uninitialized hidden name slot (nelisp-aot-compiler.el around 1566
# and 9768-9790), and the binary crashed at run time. GNU's byte compiler
# reports free variables at compile time (bytecomp.el around 3846-3860).
# The census tool (tools/ai/native-free-symbol-census.py, from wh-s4f
# 6cf24d3d9) found 3 such sites before the fix.
# Base: eval/core-20261017 at 9d5f4a515.
