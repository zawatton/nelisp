#+TITLE: Symbols: GNU 31.1 struct Lisp_Symbol with direct cells and the redirect model

# User decision 2026-10-21: fix the representation first, imitating GNU.
# Profiles show variable and function access going through a name-hashed
# mirror table:
# - the .elc benchmark spends about 9% in nl_intern_hash, symname_probe,
#   intern_eq and fnv1a;
# - buffer operations run mirror_bucket_prepend and name hashing on every
#   switch and set.
#
# GNU 31.1:
# - lisp.h struct Lisp_Symbol holds the name, the value (by redirect), the
#   function, the plist and next.
# - redirect is one of SYMBOL_PLAINVAL, SYMBOL_VARALIAS, SYMBOL_LOCALIZED
#   (a blv) and SYMBOL_FORWARDED.
# - data.c find_symbol_value, set_internal, indirect_variable and
#   swap_in_symval_forwarding read and write through the symbol itself, with
#   no lookup by name.
#
# This lane also owns the symbol half of word-heap S3 (header-less symbols).
#
# Base: eval/integ-20261021w (eval/core 7d2d49fa3 plus the word-heap line,
# in final checks).
# - callpath-perf already gave function reads direct cells (its steps 1a and
#   1c, on the word-heap line); build on that layout, not beside it.
# - buffer-native owns the blv internals and is not yet on this base.
#   LOCALIZED interop is planned in S0.1 and implemented after buffer-native
#   is merged onto this base.
#
# Bar: wall-clock own cost against GNU 31.1, as paired per-round ratios on
# CPU 13 (COMMON.md Measurement).
