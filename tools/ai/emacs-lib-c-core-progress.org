#+TITLE: nelisp-emacs-lib -- GNU Emacs C-core coverage in NeLisp Lisp

Objective (user, 2026-09-30): implement every GNU Emacs 31.1 C primitive for the
NeLisp runtime in Lisp (nelisp-emacs-lib), keeping native implementations to the
bare minimum.  Areas and the missing set come from tools/c-core-coverage.sh
(regenerate: `tools/c-core-coverage.sh regen`, ~1 min; checks read its fresh
output and fail when it is older than the bundle or the binary).  Baseline
2026-09-30: 786/1460 bound after bootstrap; missing x-gui 31, display 213,
process 136, buffer 77, chars 54, files 43, other 120.

"Bound" is not "equivalent": each area also needs a host ERT file and an
end-to-end parity smoke that runs the standalone after the bundle loads and
diffs against host `emacs --batch` (GNU 31.1).  Batch semantics are the
reference for display/GUI functions (what GNU returns with no window system).

* C1 X11/GUI primitives (x-*) with GNU batch semantics

** C1.1 No x-gui C primitive is unbound after the bootstrap bundle loads
#+REQUIRES: NELISP_BIN
cmd: sh tools/c-core-coverage.sh check x-gui

** C1.2 Host ERT for the x-gui implementations passes on GNU Emacs 31.1
cmd: timeout 50 emacs -Q --batch -L src -L test -l test/c-core-x-gui-test.el -f ert-run-tests-batch-and-exit

** C1.3 End to end: the x-gui parity smoke matches host emacs --batch on the standalone after the bundle loads
#+REQUIRES: NELISP_BIN
cmd: sh test/c-core-x-gui-parity-smoke.sh
