# Reported 2026-11-06 by the notes-9b session (MAGIT-GIT-EXEC: git ran in the
# wrong directory from temp buffers).  GNU's default-directory is a per-buffer
# C variable: always local in every buffer, and get-buffer-create /
# generate-new-buffer copy the current buffer's value.  On this line it is a
# plain global, even under plain --load (build 196 differs on 7 of 10 lines).
# BD_BIN is a binary built from this tree.
