#+TITLE: Doc 236 gradual type checking — Stages 1-2 and build gate

# Run from the repository root:
#   bin/progress-meter.sh --ledger tools/ai/gradual-typecheck-progress.org
# (bin/progress-meter.sh lives in the Notes workspace.)
# GNU_LISP_DIR points at a GNU Emacs lisp/ tree (e.g. /usr/share/emacs/31.1/lisp).
# NELISP_BIN points at a built standalone target/nelisp binary.

* S1 Primitive signature table

** S1.1 Primitive table unit tests pass
#+TIMEOUT: 300
cmd: make typecheck-test-prims

** S1.2 Cross-check against GNU comp-known-type-specifiers runs and writes a disagreement report
#+TIMEOUT: 300
cmd: make typecheck-prims-crosscheck && test -s target/typecheck/prims-crosscheck.txt

** S1.3 Negative control: a corrupted table entry is reported as a disagreement
#+TIMEOUT: 300
cmd: grep -q 'ert-deftest nl-typecheck-prims-negative-control' packages/nl-typecheck/test/*.el && make typecheck-test-prims TYPECHECK_TEST_SELECTOR=nl-typecheck-prims-negative-control

* S2 Checker with local flow typing

** S2.1 Checker ERT suite passes (inference, narrowing, gradual consistency)
#+TIMEOUT: 300
cmd: make typecheck-test

** S2.2 Negative control: an injected declared-type clash is an error and fails the gate
#+TIMEOUT: 300
cmd: F=packages/nl-typecheck/test/fixtures/clash.el; mkdir -p target/typecheck; test -f $F && ! make typecheck-gate TYPECHECK_FILES=$F >target/typecheck/neg-clash.log 2>&1 && grep -q 'clash.el:[0-9]*:[0-9]*: error: ' target/typecheck/neg-clash.log

** S2.3 Positive control: the clash fixture's fixed twin passes the gate
#+TIMEOUT: 300
cmd: make typecheck-gate TYPECHECK_FILES=packages/nl-typecheck/test/fixtures/clash-fixed.el

** S2.4 End to end: zero error diagnostics on GNU Emacs lisp/ subset (vendored-scope rules)
#+REQUIRES: GNU_LISP_DIR
#+TIMEOUT: 600
cmd: make typecheck-vendor GNU_LISP_DIR="$GNU_LISP_DIR"

* S3 Build gate

** S3.1 make compile runs the type-check gate
cmd: make -n compile 2>/dev/null | grep -q 'nl-typecheck-gate'

** S3.2 Typed module strictness: a warning in a nelisp-typed module fails the gate
#+TIMEOUT: 300
cmd: F=packages/nl-typecheck/test/fixtures/typed-warning.el; mkdir -p target/typecheck; test -f $F && ! make typecheck-gate TYPECHECK_FILES=$F >target/typecheck/neg-typed.log 2>&1 && grep -q 'typed-warning.el:[0-9]*:[0-9]*: warning: ' target/typecheck/neg-typed.log

** S3.3 lisp/ warning ratchet: injecting one new warning fails, baseline passes
#+TIMEOUT: 600
cmd: sh tools/typecheck-ratchet-negative.sh

** S3.4 End to end: full gate over lisp/ passes against the checked-in baseline
#+TIMEOUT: 600
cmd: make typecheck-gate

** S3.5 End to end: checker loads and checks the clash fixture on standalone target/nelisp
#+REQUIRES: NELISP_BIN
#+TIMEOUT: 300
cmd: sh packages/nl-typecheck/test/standalone-smoke.sh "$NELISP_BIN"
