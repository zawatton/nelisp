#+TITLE: Replace NeLisp copies of vendored GNU files with the vendored files

# User request 2026-11-05: replace every NeLisp file that shadows a vendored
# GNU Emacs 31.1 file of the same name (26 found) with the vendored file, in
# stages, fixing the NeLisp gaps that stop each vendored file from loading
# instead of reimplementing GNU code.  A criterion passes when no NeLisp copy
# of the file remains, the binary's `locate-library' resolves it under
# vendor/, `require' succeeds and a public GNU function of it is defined.
# VENDOR_BIN is a binary built from this tree.

* S1 GNU autoloads, rx, subr-x, url-parse

** S1.1 GNU autoload cookies of the vendored files are declared at startup
#+REQUIRES: VENDOR_BIN
cmd: bash tools/ai/vendor-replace/run-autoload.sh

** S1.2 rx.el is served by its vendored GNU file
#+REQUIRES: VENDOR_BIN
cmd: bash tools/ai/vendor-replace/run.sh rx rx rx-to-string

** S1.3 subr-x.el is served by its vendored GNU file
#+REQUIRES: VENDOR_BIN

# Expected output generated 2026-11-06 with GNU 31.1:
#   CLGNU_CORPUS=tools/ai/vendor-replace/corpus-json.el emacs --batch -Q -l tools/ai/cl-gnu/run-corpus.el

cmd: (ulimit -v 8388608; timeout 120 "$VENDOR_BIN" --load tools/ai/vendor-replace/ert-smoke.el 2>/dev/null) | grep -aqx 'ERT-SMOKE 3/4 unexpected=1'
