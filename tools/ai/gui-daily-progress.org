#+TITLE: nelisp-emacs-lib -- GUI daily driver (with a terminal stage first)

Objective (user, 2026-10-05): use NeLisp (nemacs) as a daily-driver GUI editor in
place of GNU Emacs.  The user chose a staged plan and then stated the target is
GUI daily use, so the terminal is kept only as the cheapest end-to-end harness
for the shared foundation (S1, S2), not as a product of its own.  Byte compilation and native-comp
are owned by another session and are out of scope here.

Rules: progress is reported only from bin/progress-meter.sh on this file.
Every stage ends with an end-to-end criterion driven like a user (pty for the
terminal, Xvfb for the GUI), compared with GNU Emacs 31.1 where the behaviour is
observable.  Pending criteria count as not done; known-red checks stay failing
commands.  Criteria are refined (pending -> cmd) as the harnesses land; every
change to the criteria list is recorded in a NOTE.
