# The string-match cost does not depend on the string's length (60, 600 and
# 6000 characters cost the same): it is a fixed per-call overhead. A syntax
# class pattern pays about one char-syntax-sized lookup per character.
# GNU's references:
# - syntax.h SYNTAX_ENTRY/SYNTAX: CHAR_TABLE_REF on the buffer's syntax
#   table, then the class from the entry's car;
# - chartab.c char_table_ref: O(1) through sub-char-tables;
# - search.c compile_pattern: a cache hit compares the pattern, the
#   translate table, posix and multibyte, and the syntax table by identity
#   (search.c:222).
#
# Base: eval/integ-20261021d at bdc34c979 (9d5f4 plus version,
# free-symbol, regex-syncache and casetab).
#
# Bar (the user's): an operation's own cost, that is the call minus a
# same-shape trivial subr call, is at most GNU's own cost. It is measured
# in wall-clock: the median of 7 alternating runs on idle pinned CPUs.
# Instruction counts may be reported as well, but they do not decide.
